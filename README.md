# 자율주행차 배터리 AI 공장 ① 엔진부 제작 — 불량품 판정기(분류) · 수명 예측 장치(회귀)

> **이 공장의 두 제품** — 자율주행차에 들어가는 대용량 배터리(수십 Ah급 셀)를 다룹니다. 분류 모델을 엔진으로 단 **배터리 불량품 판정기**(`index.html`)와 회귀 모델을 엔진으로 단 **배터리 수명 예측 장치**(`regression.html`). 두 페이지의 3D 공장은 같은 12공정 배치·같은 캐릭터 자리를 쓰고, 컨베이어 위 제품 앞면만 다릅니다(판정기 = 초록·빨강 표시등, 예측 장치 = 바늘 계기판). 표지 두 장도 같은 장면에서 제품 앞면만 바꿉니다. 셀 측정값(내부저항 1.2 mΩ, 용량 60 Ah 근처)은 설명용 값이며, 모델은 표준화한 값만 쓰므로 단위를 바꿔도 결과 수치는 같습니다.

배터리 셀 데이터세트로 **불량품 판정기**를 만드는 연구실 해설 시리즈의 1편입니다. 데이터세트를 만들고, **머신러닝 도감**과 **신경망 도감**에서 엔진(모델) 9종을 꺼내 판정기에 달아 시운전·비교합니다. 신경망 엔진은 AI 파라미터 카드 10장을 옮긴 **정비 작업장 10곳**에서 분해 정비합니다. 고른 엔진은 출고되어 **2편 시뮬레이션 검증**(봉인 시험 셀, 라인 시뮬레이션)으로 넘어갑니다. 연구실 스킬 ai-lab-explainer v1.14("낮의 연구실", 흰 배경)를 따릅니다.

- 사이트(올린 뒤): https://adminmrobo.github.io/how_to_make_ai_model_factory_version/
- 글 · 안상선 ((주)M-Robo 대표) · [저자 소개](https://adminmrobo.github.io/who_am_i/who_am_i.html)

## 구성 (`index.html` 한 파일)

| 섹션 | 내용 |
|---|---|
| 엔진(모델) 조립 공장 3D 그림 | 12공정: P1~P4 데이터세트 → P5 머신러닝 도감관 · P6 신경망 도감관 → P7 엔진 장착 → P8 시운전 벤치 → P9 정비 ①~⑩ → P10 비교·선정 → P11 출고 → P12 2편 검증장(공사 중) |
| 공장 현황판 | 장착 엔진, 벤치 순위, 정비 작업장 10곳의 검사 램프 |
| 데이터세트 | 셀 1,000개 × 측정값 4개, 불량 약 20%, 훈련 600 · 검증 200 · 시험 200(2편까지 봉인) |
| 엔진 창고 | 머신러닝 도감 7종(로지스틱 회귀·결정 트리·랜덤 포레스트·그래디언트 부스팅·SVM·나이브 베이즈·k-최근접 이웃) + 신경망 도감 2종(DFF·오토인코더), CNN·LSTM은 보관 |
| 장착·시운전 | 엔진마다 손잡이 하나, 판정 경계 지도, 혼동 행렬 |
| 벤치 | 9종 같은 조건 비교(검증 F1 · 훈련 F1 · 저장 값) |
| 정비 ①~⑩ | 카드 01~10 = 부품 창고 · 뉴런 조립대 · 설계도실 · 계량실 · 첫 시동 · 원인 추적실 · 조정대 · 길들이기 라인 · 개조 공정 · 출고 검사실 |
| 대결 | 로지스틱 회귀(5개) vs DFF(49개), 훈련·검증을 10번 나눠 평균 F1과 이긴 횟수로 판정 → **R 주판봇 승** |
| 출고 | 엔진 선정, 2편 예고 |
| 지식 색인 · 꾸러미 | `#kg`, `#export` (노드 99 · 관계 150 · 문헌 17) |

기본 설정 벤치(시드 고정, `node code/check_numbers.js`로 재현) — 검증 F1: DFF 0.894 · SVM 0.828 · k-최근접 0.784 · 로지스틱 0.782 · 부스팅 0.771 · 랜덤 포레스트 0.711 · 나이브 베이즈 0.667 · 결정 트리 0.636 · 오토인코더 0.581.

엔진 9종은 외부 라이브러리 없이 이 저장소(`build/engines.js`)에서 직접 구현한 단순판입니다. 예컨대 부스팅은 XGBoost 자체가 아니라 같은 원리의 작은 구현입니다.

## 자매편: 배터리 수명 예측 장치 ① 엔진부 (`regression.html`)

같은 셀 1,000개로 **수명(충·방전 횟수)**을 맞히는 예측 장치를 만듭니다. 섹션 순서는 판정기 편과 같고, 두 페이지는 서로 링크됩니다.

| 섹션 | 회귀 편에서 바뀐 점 |
|---|---|
| 데이터세트 | 수명 평균 1,078회 · 표준편차 92회(훈련), 수명도 표준화해 배우고 성적은 회로 되돌려 잼 |
| 엔진 창고 | 머신러닝 도감 8종(선형 회귀·릿지·라쏘·회귀 트리·랜덤 포레스트·그래디언트 부스팅·k-최근접 이웃·가우시안 프로세스) + DFF(출력 항등) |
| 장착·시운전 | 예측 지형 지도, 실제–예측 그림, 허용 오차 슬라이더와 과대예측(길게 틀린 셀) 개수 |
| 벤치 | 검증 평균 오차(MAE, 낮을수록 좋음) · R² · 5번 나눈 평균 ± 편차 |
| 정비 ①②⑤⑧⑨⑩ | ① 출력 부호 검사(카드 01 값은 4칸 모두 틀림) · ② 카드 02의 z = −1.8은 수명 점수로는 맞음 · ⑤ 제곱 손실과 평균 기준선 · ⑧ 손실 + 검증 MAE + 실제–예측 · ⑨ 공장 B 60셀 미세조정 · ⑩ 용량 실험(MAE) |
| 대결 | 릿지(5개) vs 그래디언트 부스팅(100그루), 정답 셀 40개·600개 × 10번 나누기 → **C 조건부** (40개: 릿지 41.3 vs 47.2회, 부스팅 0/10 · 600개: 38.0 vs 29.0회, 부스팅 10/10) |
| 장착 (감사 반영) | 비대칭 비용 슬라이더(과대 1회 = 과소 k회)와 최소 비용 여유분, 가우시안 프로세스 95% 예측 구간 |
| 잡음 바닥 | 수명 공식 잡음(표준편차 30회) → 평균 오차 바닥 ≈ 23.9회, 데이터세트·벤치에 표시 |
| 지식 색인 · 꾸러미 | 노드 103 · 관계 161 · 문헌 19 (`build/kg_reg.json`·`refs_reg.json`·`meta_reg.json`) |

5번 나눈 평균 검증 오차(회): DFF 26.1±0.9 · 가우시안 프로세스 27.0±1.8 · 부스팅 28.8±1.8 · 랜덤 포레스트 33.0±1.6 · k-최근접 33.8±1.7 · 선형 38.0±1.6 · 릿지 38.2±1.7 · 라쏘 38.7±1.9 · 회귀 트리 48.0±3.1. 1·2위 차이(0.9회)는 흔들림보다 작아 "비슷하게 좋다"로 읽습니다. 정비 수치: ⑧ 검증 MAE 23.2회(에포크 90) · ⑨ 그대로 157.1 / 처음부터 42.7 / 전체 27.8 / 어댑터 25.9회 · ⑩ 시드 3개 평균 검증 MAE 최저는 은닉 2개(31.4회, 2위 은닉 4개 32.7회와 차이는 흔들림 안), 은닉 32개는 훈련 10.0 / 검증 39.3회.

## 데이터
배터리 셀 1,000개(공장 A)와 400개(공장 B)는 시드로 만든 **설명용 모형**이며 실제 측정값이 아닙니다(`build/bm.js`).

## 다시 만들기
```
python3 build/kg_defs.py       # kg.json · refs.json · meta.json
python3 build/kg_reg.py        # kg_reg.json · refs_reg.json · meta_reg.json (회귀 편)
python3 build/reg_make.py      # page.src.html → reg.src.html (회귀 편 본문)
python3 build/reg_js_make.py   # page.js → reg.js (회귀 편 스크립트)
node build/build.js            # → index.html · regression.html
node code/check_numbers.js     # 기대 수치 확인 (분류)
node code/check_reg.js         # 기대 수치 확인 (회귀)
python3 code/browser_check.py  # (선택) 헤드리스 브라우저 점검 · PAGE=regression.html 로 회귀 편
```
`build/`: page.src.html(본문) · page.style.html · page.js(페이지 스크립트) · bm.js(데이터·신경망) · engines.js(분류 엔진 9종) · engines_reg.js(회귀 엔진 9종) · reg.src.html · reg.js · common.css/common.js(공용 모듈) · kgx.js(지식 색인·꾸러미) · sprites96.js(캐릭터 팩 38장).
